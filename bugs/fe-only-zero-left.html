Product says “Only 0 left in stock” but can still be added to the cart

P3 · MinorBeginnerProduct

Want to find it yourself first? This page gives away the answer. Play this bug on a fake app screen and see if you can spot it in three tries.

Spot this bug

The clue

Read the stock message next to the button.

Steps to reproduce

  1. Open a product whose stock has just run out
  2. Read the stock message and the buttons

Expected result

“Out of stock” with the buy buttons disabled (or a “Notify me” button)

Actual result

“Hurry! Only 0 left in stock” with Add to cart and Buy now still active

Why it matters

This is a minor (P3) bug. It does not stop anyone, but it looks careless and makes people trust the product less. It is usually fixed in a normal sprint.

Testing tip

Test stock at 1, 0 and below. Messages written for “a few left” often never handle zero.

How to find bugs like this

Frontend bugs are the ones users see on the screen: wrong totals, labels that do not match, broken layouts, dates that cannot be right and buttons that say the wrong thing. When you test, try these checks:

  • Add up every total and compare numbers that should match.
  • Read every label, plural and date out loud.
  • Try the smallest and largest values a field allows.
  • Check the screen on a small phone and with long text.
