A 4-character password is rated “Strong”

P2 · MajorIntermediateSign up

Want to find it yourself first? This page gives away the answer. Play this bug on a fake app screen and see if you can spot it in three tries.

Spot this bug

The clue

How long is that password?

Steps to reproduce

  1. Open Set a password
  2. Type a 4-character password

Expected result

Weak, and the rule “At least 8 characters” fails

Actual result

Strength shows Strong next to a failing rule

Why it matters

This is a major (P2) bug. The feature still works in part, but users get wrong information or a broken step, and many will notice. It should be fixed before or soon after release.

Testing tip

Check that every indicator agrees. Try short, long, all-numbers and common passwords.

How to find bugs like this

Frontend bugs are the ones users see on the screen: wrong totals, labels that do not match, broken layouts, dates that cannot be right and buttons that say the wrong thing. When you test, try these checks:

  • Add up every total and compare numbers that should match.
  • Read every label, plural and date out loud.
  • Try the smallest and largest values a field allows.
  • Check the screen on a small phone and with long text.
