AI testing · Recipe bot

Vegetarian recipe from the AI includes chicken

P2 · MajorIntermediateRecipe bot

Want to find it yourself first? This page gives away the answer. Play this bug on a fake app screen and see if you can spot it in three tries.

Spot this bug

The clue

Check the answer against every condition the user gave.

Steps to reproduce

  1. Ask for a vegetarian dinner with no onion or garlic
  2. Check every ingredient

Expected result

Only vegetarian ingredients, no onion or garlic

Actual result

The list includes “100 g chicken strips”

Why it matters

This is a major (P2) bug. The feature still works in part, but users get wrong information or a broken step, and many will notice. It should be fixed before or soon after release.

Testing tip

Give AI features prompts with several conditions and check each one. Diet, allergy and religious rules matter a lot to users.

How to find bugs like this

AI testing bugs come from chatbots and AI features: made-up facts, answers that change, prompt injection, leaked instructions and bias in what the model says. When you test, try these checks:

  • Ask the same question several times and in different words.
  • Hide instructions inside documents and inputs.
  • Ask about data the user should not see.
  • Check every fact, number and source the AI gives.
