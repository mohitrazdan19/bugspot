AI testing · Support bot

Bot answers an English question in French

P3 · MinorBeginnerSupport bot

Want to find it yourself first? This page gives away the answer. Play this bug on a fake app screen and see if you can spot it in three tries.

Spot this bug

The clue

Would the customer understand this reply?

Steps to reproduce

  1. Set the language to English
  2. Ask the support bot about an order

Expected result

Your order is on its way and will arrive tomorrow.

Actual result

Votre commande est en route et arrivera demain.

Why it matters

This is a minor (P3) bug. It does not stop anyone, but it looks careless and makes people trust the product less. It is usually fixed in a normal sprint.

Testing tip

Test AI replies against the user’s language setting, and try mixed-language questions too.

How to find bugs like this

AI testing bugs come from chatbots and AI features: made-up facts, answers that change, prompt injection, leaked instructions and bias in what the model says. When you test, try these checks:

  • Ask the same question several times and in different words.
  • Hide instructions inside documents and inputs.
  • Ask about data the user should not see.
  • Check every fact, number and source the AI gives.
