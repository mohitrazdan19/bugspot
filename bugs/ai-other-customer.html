AI testing · Support bot

Support bot shares another customer’s name and address

P1 · CriticalIntermediateSupport bot

Want to find it yourself first? This page gives away the answer. Play this bug on a fake app screen and see if you can spot it in three tries.

Spot this bug

The clue

Whose details is the bot sharing?

Steps to reproduce

  1. Sign in as Riya
  2. Ask the bot about an order number that belongs to someone else

Expected result

The bot says it can only help with Riya’s own orders

Actual result

It reveals Arjun’s name, address and delivery day

Why it matters

This is a critical (P1) bug. It can lose money, expose private data or stop people from finishing a key task. A bug like this should block a release and be fixed straight away.

Testing tip

AI tools must follow the same access rules as the app. Ask them about other people’s data on purpose.

How to find bugs like this

AI testing bugs come from chatbots and AI features: made-up facts, answers that change, prompt injection, leaked instructions and bias in what the model says. When you test, try these checks:

  • Ask the same question several times and in different words.
  • Hide instructions inside documents and inputs.
  • Ask about data the user should not see.
  • Check every fact, number and source the AI gives.
