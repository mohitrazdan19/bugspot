Daily revenue in INR adds dollars and rupees together

P2 · MajorExperiencedReports

Want to find it yourself first? This page gives away the answer. Play this bug on a fake app screen and see if you can spot it in three tries.

Spot this bug

The clue

Can these amounts be added together?

Steps to reproduce

  1. Take payments in INR and USD on the same day
  2. Run the revenue report

Expected result

USD converted first: 999 + 250 + (599 × rate) ≈ ₹51,000

Actual result

revenue_inr = 1848.00 (999 + 599 + 250)

Why it matters

This is a major (P2) bug. The feature still works in part, but users get wrong information or a broken step, and many will notice. It should be fixed before or soon after release.

Testing tip

Before summing money, check every row is in the same currency. Group by currency or convert first.

How to find bugs like this

Database bugs show up when you look at the tables: duplicate rows, joins that double totals, deleted users still active, values cut short or saved in the wrong type. When you test, try these checks:

  • Run the query yourself and count the rows.
  • Look for duplicates that differ only in case or spaces.
  • Check deleted and archived records.
  • Compare stored values with what the user typed.
