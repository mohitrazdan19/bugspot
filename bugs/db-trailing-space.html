Database testing · Users table

Email saved with a trailing space, so the user can never sign in

P3 · MinorExperiencedUsers table

Want to find it yourself first? This page gives away the answer. Play this bug on a fake app screen and see if you can spot it in three tries.

Spot this bug

The clue

Look very closely between the quotes.

Steps to reproduce

  1. Sign up with “riya@mail.com ” (space at the end, common on phones)
  2. Sign in with riya@mail.com

Expected result

Spaces are trimmed before saving, and sign-in works

Actual result

"riya@mail.com " is stored and does not match

Why it matters

This is a minor (P3) bug. It does not stop anyone, but it looks careless and makes people trust the product less. It is usually fixed in a normal sprint.

Testing tip

Try leading and trailing spaces in every text field. Phone keyboards add them after autocomplete.

How to find bugs like this

Database bugs show up when you look at the tables: duplicate rows, joins that double totals, deleted users still active, values cut short or saved in the wrong type. When you test, try these checks:

  • Run the query yourself and count the rows.
  • Look for duplicates that differ only in case or spaces.
  • Check deleted and archived records.
  • Compare stored values with what the user typed.
